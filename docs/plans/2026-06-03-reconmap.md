# reconmap — Implementation Plan

## Project Overview

**reconmap** — Passive Attack Surface Intelligence Platform

Tagline: Continuous, fully-passive external attack surface monitoring for any org.

Target audience: Security teams, bug bounty hunters, red teamers needing continuous domain visibility.

Portfolio value: Shows async pipeline design, multiple API integrations, change detection engine, graph data model, clean SDK/CLI design.

---

## Design Decisions

- **Storage**: SQLite by default (zero-infra dev), switchable to PostgreSQL via `DATABASE_URL` env var
- **No Celery/Redis**: asyncio workers per scan session — sufficient for portfolio, avoids infra overhead
- **API keys**: Shodan and GitHub tokens optional; collectors gracefully degrade (skip or use free tier) if absent
- **Python**: `py -3.10` — match apifuzz
- **Build backend**: hatchling
- **Data sources (passive only)**:
  - crt.sh — Certificate Transparency logs (free, no key)
  - Shodan — port/service/banner data (free API key)
  - GitHub Code Search — secrets/hardcoded endpoints in public repos (GitHub PAT)
  - DNS — async resolution of discovered subdomains (dnspython, no key)

### Task 3 — BaseCollector + crt.sh collector

**What:** `src/reconmap/collectors/base.py` and `src/reconmap/collectors/certstream.py`.

**BaseCollector:**
```python
from abc import ABC, abstractmethod
from reconmap.models.asset import AssetSnapshot

class BaseCollector(ABC):
    name: str = ""
    requires_key: bool = False

    @abstractmethod
    async def collect(self, domain: str) -> AssetSnapshot:
        """Collect passive recon data for domain. Return partial AssetSnapshot."""
        ...

    def is_available(self) -> bool:
        """Return False if requires_key=True and key not configured."""
        return True
```

**CertStreamCollector:**
- Queries `https://crt.sh/?q=%.{domain}&output=json`
- Returns deduplicated subdomains of target domain
- Each result → `Subdomain(source="certstream", ...)`
- Parses JSON response: each entry has `name_value` (may contain `\n`-separated names), `not_before`
- Filter: only include names that end with `.{domain}` or equal `{domain}`
- Strip `*.` prefix from wildcard entries
- Set `first_seen = last_seen = parsed not_before date` from crt.sh
- Dedup by subdomain name (keep latest `last_seen`)
- Return `AssetSnapshot` with `subdomains` populated, `ports=[]`, `leaks=[]`
- Timeout: 30s
- If crt.sh returns non-200 or times out, return empty snapshot (log warning, don't raise)

- Test: multiline `name_value` handled

### Task 4 — Shodan collector

**What:** `src/reconmap/collectors/shodan.py`

**ShodanCollector:**
- Uses Shodan InternetDB API: `https://internetdb.shodan.io/{ip}` (free, no key needed for basic data)
- Workflow:
  1. Resolve domain → IPs (via `socket.getaddrinfo` or passed IPs)
  2. For each IP, query `https://internetdb.shodan.io/{ip}`
  3. Response: `{"ip": "...", "ports": [...], "hostnames": [...], "tags": [...], "cpes": [...], "vulns": [...]}`
  4. Map each port → `Port(ip=ip, port=p, protocol="tcp", service=..., source="shodan")`
  5. Service name: try to infer from port number (80→"http", 443→"https", 22→"ssh", 21→"ftp", 25→"smtp", 3306→"mysql", 5432→"postgresql", 6379→"redis", 27017→"mongodb", else "")
- `requires_key = False` (InternetDB is free)
- Timeout per IP: 10s
- Skip IPs that return 404 (no Shodan data) or timeout
- Return `AssetSnapshot` with `ports` populated

**Tests in `tests/collectors/test_shodan.py`:**

- Test: multiple IPs for same domain → all ports returned

### Task 5 — GitHub secrets collector

**What:** `src/reconmap/collectors/github.py`

**GitHubCollector:**
- Uses GitHub Search API: `https://api.github.com/search/code?q={domain}&per_page=30`
- Auth: `Authorization: token {github_token}` header if token provided
- `requires_key = False` (but rate limit is 10/min unauth vs 30/min auth — handle 429 gracefully)
- Secret detection regexes (applied to each file's content via `text_matches`):
  ```python
  SECRET_PATTERNS = {
      "aws_key":      re.compile(r"AKIA[0-9A-Z]{16}"),
      "aws_secret":   re.compile(r"[A-Za-z0-9/+=]{40}"),  # combined with context
      "jwt":          re.compile(r"eyJ[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+"),
      "private_key":  re.compile(r"-----BEGIN (RSA |EC )?PRIVATE KEY-----"),
      "api_key":      re.compile(r'(?i)(api[_-]?key|apikey|api[_-]?secret)\s*[:=]\s*["\']?([A-Za-z0-9_\-]{20,})["\']?'),
      "password":     re.compile(r'(?i)(password|passwd|pwd)\s*[:=]\s*["\']([^"\']{8,})["\']'),
      "github_token": re.compile(r"gh[pousr]_[A-Za-z0-9]{36}"),
  }
  ```
- For each code search result:
  - Extract `repository.full_name`, `path`, `html_url`
  - Check `text_matches[].fragment` against each SECRET_PATTERNS regex
  - If match: create `SecretLeak(secret_type=..., raw_match=_redact(match), ...)`
  - `_redact(match)`: show first 4 chars + `****` — never log full secret
- Return `AssetSnapshot` with `leaks` populated
- If no token: still query but accept 403/429 gracefully (return empty leaks, log)
- Rate limit: sleep 6s between requests to stay under 10/min unauth

**Tests in `tests/collectors/test_github.py`:**
- Mock GitHub Search API (use respx)

- Test: JWT in text_matches → SecretLeak with secret_type="jwt"
- Test: raw_match is redacted (no full secret in output)
- Test: 429 response → empty leaks, no exception
- Test: 403 response → empty leaks, no exception
- Test: no matches → empty leaks
- Test: multiple matches in one file → multiple SecretLeak objects

### Task 6 — DNS resolver collector

**What:** `src/reconmap/collectors/dns_resolver.py`

**DNSResolverCollector:**
- Takes list of already-discovered subdomains (from other collectors or provided)
- Resolves each → A records (IPv4 IPs)
- Uses `asyncio` + `dnspython` with `dns.asyncresolver.resolve(name, "A")`
- Concurrency: semaphore of 20 concurrent DNS queries
- Timeout per query: 5s; on NXDOMAIN or timeout → skip, ip_addresses stays empty
- Updates `Subdomain.ip_addresses` for each resolved name
- Also adds any NEW subdomains discovered via brute-force of common prefixes:
  ```python
  COMMON_PREFIXES = ["www", "api", "mail", "smtp", "dev", "staging", "admin",
                     "test", "cdn", "static", "app", "portal", "dashboard",
                     "auth", "login", "vpn", "remote", "git", "ci", "monitor"]
  ```
  - For each prefix, try `{prefix}.{domain}` — if resolves → add as new Subdomain(source="dns")
- Return `AssetSnapshot` with updated subdomains (merged: original + newly discovered)

### Task 7 — Scanner orchestrator + diff engine

**What:** `src/reconmap/engine/scanner.py` and `src/reconmap/engine/diff.py`

**Scanner:**
```python
class Scanner:
    def __init__(
        self,
        collectors: list[BaseCollector] | None = None,
        shodan_key: str | None = None,
        github_token: str | None = None,
    ):
        ...

    async def run(self, domain: str) -> AssetSnapshot:
        """Run all available collectors concurrently, merge results."""
        ...

    def _merge(self, domain: str, snapshots: list[AssetSnapshot]) -> AssetSnapshot:
        """Merge partial snapshots. Dedup subdomains by name, ports by ip+port."""
        ...
```

- Default collectors: CertStreamCollector, ShodanCollector, DNSResolverCollector, GitHubCollector
- DNS collector runs AFTER certstream (uses discovered subdomains as input)
- CertStream + Shodan + GitHub run concurrently via `asyncio.gather`
- DNS runs after certstream finishes (needs subdomain list as input)
- Merge: dedup subdomains by `subdomain` name (union of ip_addresses), dedup ports by `(ip, port)`, dedup leaks by `(repo, file_path, line_number)`
- Returned snapshot has `snapshot_id` and `timestamp` set

**DiffEngine:**
```python
class DiffEngine:
    def diff(self, before: AssetSnapshot, after: AssetSnapshot) -> list[Change]:
        ...
```

- Compare before vs after:
  - New subdomains (in after, not in before) → `Change(change_type="new_subdomain", severity="medium")`
  - Removed subdomains → `Change(change_type="subdomain_removed", severity="low")`
  - New ports → `Change(change_type="new_port", severity="high")`
  - Closed ports → `Change(change_type="port_closed", severity="info")`
  - New leaks → `Change(change_type="new_leak", severity="critical")`
- Subdomain key: `subdomain.subdomain`
- Port key: `f"{port.ip}:{port.port}"`
- Leak key: `f"{leak.repo}/{leak.file_path}:{leak.line_number}"`
- All Changes get `snapshot_id = after.snapshot_id`

- `tests/engine/test_scanner.py`: mock collectors, verify merge/dedup logic, minimum 10 tests
- `tests/engine/test_diff.py`: test each change type, test empty before/after, test no changes → empty list, minimum 12 tests

## Testing Standards

- All async tests use `pytest-asyncio` with `asyncio_mode = "auto"`
- HTTP calls mocked with `respx` (no real network in tests)
- DNS calls mocked by patching `dns.asyncresolver.resolve`
- SQLite `:memory:` for storage tests
- Minimum test counts are hard minimums — reviewers will reject if not met
- Every test must assert something specific, not just "no exception"

---

## Git Workflow

1. Create branch `feature/task-N-name` off `main`
2. Implement + commit (conventional commits)
3. Merge `--no-ff` to `main`
4. Delete feature branch

## Non-Goals (out of scope for v0.1.0)

- Celery/Redis job queue
- pgvector similarity search
- Next.js frontend
- Paste site / job posting collectors
- dnstwist typosquatting (keep DNS resolver simple)
- Real-time WebSocket push
- Multi-user auth
